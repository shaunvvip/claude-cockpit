# v0.5.2-beta — subscriber usage limits (5h + 7d) with reset countdown

Closes the gap vs. claude-hud's display: Claude Code stdin carries `rate_limits.five_hour` + `rate_limits.seven_day` with `used_percentage` and `resets_at`. Now surfaced in both surfaces.

## What you see now

**Statusline (line 2):**
```
ctx ██████░░░░ 51%    5h ███░░ 57% (3h 31m)    7d ███░░ 65% (3d 8h)
```

**Dashboard SessionCard + detail page:**
- Two mini progress bars below the MCP health row, with reset countdown on the right
- Color thresholds: blue <75%, magenta 75-89%, red ≥90% (quota convention from claude-hud)

## Implementation

- `parseStatuslineInput` extracts `rate_limits` — clamps `used_percentage` to [0,100], normalizes `resets_at` whether CC sends ISO string or seconds-epoch number.
- `SessionState` gains 4 optional fields: `usage5hPct / usage5hResetAt / usage7dPct / usage7dResetAt`.
- statusline prefers fresh `parsed.usage5hPct` over daemon-cached value (avoids round-trip lag).
- New `formatCountdown()` helper picks `Xd Yh / Xh Ym / Xm / <1m` automatically; returns empty when reset is in the past.
- Degrades gracefully when stdin lacks `rate_limits` (older CC versions or non-subscription accounts) — nothing renders.
