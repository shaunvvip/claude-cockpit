# v0.5.4-beta — subagent counter + MCP live activity + transcript stream-parse

Three small but visible polish patches.

## 1. `subagents ×N` real count

Daemon increments `cur.taskCount` on every `TOOL_USE name='Task'`. `SessionState` gains an optional `taskCount: number` (uncapped, unlike `tools[]` which is capped at 50). Statusline reads it and renders `subagents ×N` on line 1 when N > 0:

```
● claude-opus-4-7[1m] · cockpit · main · tools 50↑ · subagents ×3 · todos 2/5 · [dash] [stop] [file]
```

Hidden when N=0 to save space.

## 2. MCP live activity

When a `TOOL_USE` matches `/^mcp__<server>__/` we update that server's `lastCallTs`. Dashboard `McpHealthBar` now:

- **Tooltip:** `"context7: healthy · last used 3m ago"` or `"… · not used yet"`
- **Active glow:** subtle `textShadow` on dots called within 5 min
- **Dim opacity 0.35** on dots idle > 30 min (configured but inactive)

## 3. TranscriptWatcher chunked drain (large-file perf)

`TranscriptWatcher.start()` previously allocated a single `Buffer.alloc(stat.size)` for the entire file. With 10+ MB transcripts that's 200-500ms of GC pressure on every fresh daemon start.

Now: reads in 256 KB chunks, carrying a partial-line tail between chunks so `JSON.parse` only sees complete lines. **Perf gate test:** 10 000-line / 2 MB transcript parses in <500ms typical.
