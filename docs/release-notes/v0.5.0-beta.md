# v0.5.0-beta — Phase 2 ships

The big one. Cockpit goes from "read-only multi-session HUD" to "alerts + actions + detail page".

## Highlights

- **Smart alerts (4 rules)** — `ctx-high` / `cost-spike` / `loop-detect` / `subagent-stuck` fire native macOS/Linux system notifications with deep-link to the session detail page. Configurable / toggle-able via `~/.claude-cockpit/config.json`.
- **Working control actions** — `[stop]` (SIGINT to Claude Code main, with ppid validation) / `[file]` (open last-edited file in $EDITOR) / `[dash]` OSC 8 links in the statusline + dashboard buttons (Stop / Open file / Copy id / Focus terminal).
- **Session detail page** — `/sessions/:id` with live CTX chart (µPlot ringbuf), 5-min tool bar chart, todos, full-width event timeline, and AlertBanner that highlights the rule that brought you here.
- **Slice-by-slice delivery** — 26 implementation tasks across 4 vertical slices, each demoable end-to-end before moving on.

## What's under the hood

- `RuleEngine` with 10s tick, dedup window per `(sessionId, ruleId)`, in-memory rolling cost baseline for `cost-spike`.
- `EventBuffer` (200-entry FIFO per session) backing the detail-page timeline and rule context.
- `AlertStore` (50-entry ring) for `/api/sessions/:id/recent-alerts` queries.
- `TranscriptWatcher` extended with `FILE_EDIT` events for `[file]` jump + loop-detect.
- New HTTP endpoints: `POST /interrupt`, `POST /open-file`, `POST /copy-info`, `POST /focus-terminal`, `GET *-redirect` (OSC 8 bridge with Origin guard), `GET /events`, `GET /recent-alerts`.
- WS protocol gets an `ALERT` frame variant for in-app toast (Phase 3).

## Risk mitigations landed

- **R2** (PID misidentification) — `/interrupt` validates ppid's `comm` contains `claude` before SIGINT, returns `422 stop-unavailable` otherwise.
- **R7** (macOS notification permission) — one-shot "claude-cockpit ready" notification at first daemon start surfaces the permission prompt early.
- **R13** (CSRF on GET redirects) — Origin check against `localhost:<port>`; empty Origin allowed (direct terminal GET), foreign Origin → 403.
- **R14** (focusTerminal not always available) — soft-fail; daemon never crashes when `wmctrl` is missing or AppleScript lacks Accessibility permission.
