# v1.0.0-beta.1 — Dashboard polish patch

Three UI bugs caught during post-tag smoke of v1.0.0-beta. No API or
schema changes — drop-in replacement.

## Fixes

- **Sidebar follows theme** — sidebar background was hardcoded
  `bg-[#0a0e12]`, stayed black under `data-theme='light'`. Now
  uses `bg-cockpit-panel` CSS variable; flips with the rest of the
  chrome. Active-link highlight switched to `bg-cockpit-bg` so it
  remains legible in both themes.

- **Theme & language toggles visible** — `<aside>` wasn't a flex
  column, so the `flex-1` spacer was a no-op and the toggle buttons
  rendered immediately under the History link with no separator.
  Sidebar is now `flex flex-col min-h-screen`; the two buttons sit
  in a bordered footer row with hover feedback.

- **Session cards are clickable** — the Overview card was a plain
  `<div>`. Wrapped it in `<Link to="/sessions/$sessionId">` so the
  whole card is the click target. Hover state added (blue border).

## Compatibility

- `claude-cockpit configure` / `status` unchanged.
- Daemon API unchanged.
- Database schema unchanged.

`npm install -g claude-cockpit@1.0.0-beta.1` over an existing
v1.0.0-beta install just refreshes the bundle.
